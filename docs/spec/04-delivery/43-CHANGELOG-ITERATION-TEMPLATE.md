## 重要迁移原则

- 每次 schema 变更必须新增可追踪 migration；不在生产手动更改表结构。
- 提示词改变要**升版本**；保留旧版本及生成记录。
- 发布访问权限变更需要同时测试缓存、静态构建、附件和 AI 索引（未来）。
- 新 AI 服务先跑 FakeProvider + 小样本测试，失败能关闭功能，不影响普通发布。
